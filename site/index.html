PUB File Opener

Open Publisher files in your browser

View and print Microsoft Publisher (.pub) files without Publisher. Free, no sign-up, and your files never leave your computer.

Why won’t my .pub file open?

Microsoft retired Publisher in October 2026. Microsoft 365 no longer includes it, and Word, PowerPoint and Designer can’t open .pub files. PUB File Opener reads them directly in your browser.

Is it private?

Yes. Your file is read by code running on your own device. Nothing is uploaded, and there’s no account.

How do I save it as a PDF?

Open the file, choose Print or save as PDF, then pick Save as PDF as the printer.

Will every file look perfect?

Most newsletters, flyers, brochures and certificates open well. A few files with unusual graphics may show gaps. Batch conversion of whole folders and editable PowerPoint export are coming next.
