Open-source licenses

PUB File Opener is built on these open-source projects. Thank you to their authors.

  • libmspub (Mozilla Public License 2.0): reads Publisher files.
  • librevenge (Mozilla Public License 2.0): document framework used by libmspub.
  • rtf.js WMF and EMF renderers (MIT): draws older Windows graphics.
  • UTIF.js (MIT): decodes TIFF images.
  • pako (MIT and Zlib): decompression.
  • Boost (Boost Software License 1.0) and zlib (zlib license).
  • Emscripten runtime (MIT).

Our own code is MIT licensed. The full source is on GitHub.
